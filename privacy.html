简单ERP · 隐私政策

本政策说明「简单ERP」在你自己部署的服务器上，会收集哪些信息、用来做什么、存在哪里，以及你作为使用者享有的权利。

1. 谁在处理你的数据

本程序是开源自建系统。它不像某些商业 SaaS 那样由第三方集中运营：

  • 数据控制者：使用本系统的那家公司 / 门店（即创建并管理本套账的老板）。
  • 平台管理员：系统内置的「管理员」账号（is_admin=1），负责处理违规内容与用户反馈。
  • 软件作者：仅提供源代码，不收集、不存储、不上传任何实际运营数据。软件作者不会访问你的服务器或数据库。
换句话说：代码是公开的，数据是你自己的。请自行评估所部署环境的安全性，并定期备份数据库文件。

2. 收集哪些信息

2.1 账户信息（你主动填写）

项目内容为什么需要
登录账号你自己填写的账号（通常是手机号）用于登录与区分身份
密码以 scrypt 加盐哈希存储，不存明文身份校验；不可逆，因此管理员也无法读取你的密码
姓名 / 昵称选填小票「经手人」、操作留痕显示
角色权限老板 / 经理 / 员工决定可访问的功能范围

2.2 业务数据（为完成开单与统计所必需）

  • 门店 / 客户信息：门店名称、联系人、电话、地址、备注。
  • 商品信息：品名、条码、规格、单位、价格、每箱装量。
  • 库存：各商品当前数量与预警阈值。
  • 订单与明细：单号、日期、门店、明细品项、单价、单品折扣、整单折扣、金额、经手人。
  • 价格记忆：门店 × 商品的历史成交价与单品折扣，用于下次开单自动带出。
  • 销售数据：按日/月的销售额、订单数、排行等统计结果。

2.3 设备与会话信息（自动产生）

  • 会话令牌：登录后随机生成，存在浏览器 localStorage，用于保持登录状态；仅保存在内存与本地，服务端不落盘。
  • 信任设备记录：你勾选「信任此设备，30 天免密」后，记录一条令牌哈希（sha256）+ 设备名称 + 到期时间，用于免密登录；最多 4 台，可随时解除。
  • 网络地址：仅在内存中用于登录失败计数与限流（防暴力破解），不写入数据库、不落盘、随服务重启清空。

2.4 意见反馈（你主动提交）

  • 反馈类型（Bug / 功能需求 / 账户问题 / 其他）、文字描述、选填的联系方式。
  • 附件（最多 5 个，单个 ≤ 8MB；仅允许图片、txt/log、pdf、zip、json、csv、mp4）。
  • 提交时所在的页面与客户端版本，便于定位问题。
  • 可见范围：反馈列表仅平台管理员可查看与回复；附件仅管理员与提交者本人可下载。普通用户之间互相不可见。

3. 这些信息怎么用

仅用于以下目的，不做其他用途：

  1. 完成登录与身份验证、维持会话。
  2. 生成销售订单、更新库存、保存门店历史价与折扣。
  3. 生成与打印小票（含条码）、订单预览、销售统计与分析。
  4. 按角色权限隔离数据（老板 / 经理 / 员工可见范围不同），并按套账隔离不同公司的数据。
  5. 生成图形验证码（用于防机器人注册与暴力破解）。
  6. 检测违规内容并按规则提醒整改；处理用户提交的意见反馈。
  7. 在你勾选信任设备时，实现 30 天免密登录。
本系统没有广告、没有用户行为画像、没有数据上报。业务数据不会离开你自己的服务器。

4. 存在哪里、存在多久

数据存储位置保留期限
全部业务与账户数据你自己服务器上的 SQLite 数据库文件（默认 data/erp.db）直到你主动删除
反馈附件服务器 uploads/feedback/ 目录，文件名重新随机生成直到你主动删除
会话令牌服务端内存（Map），不落盘服务重启即全部失效
登录失败计数 / IP 限流服务端内存服务重启即清空
验证码服务端内存，有效期 5 分钟自动过期
信任设备令牌哈希数据库，默认有效期 30 天到期或解除后失效
⚠ 备份提醒：数据仅存在你自己服务器上。请定期备份 data/erp.db（连同 -wal/-shm 文件，或用 SQLite 的 .backup 命令做一致性备份）。本项目不提供云端备份，也无从代为恢复。

5. 明确不收集什么

本程序不会收集、也不会存储以下内容：

  • 通讯录、短信、通话记录、相册、麦克风、摄像头（扫码与拍照功能只在你主动点击时调用，用完即停，不录制、不上传、不留存）。
  • 精确地理位置（GPS）。
  • 第三方平台的账号、好友关系、支付信息。
  • 任何用于「画像」或「推荐」的标签、追踪标识（如广告 ID、设备指纹）。
  • 键盘输入内容（除反馈框中你自己主动输入的文字外，不做键盘记录）。

6. 第三方与外部服务

服务用途会传给谁
Cloudflare（若你在前面套了 CDN）HTTPS 加速与静态缓存按 Cloudflare 自身隐私政策处理访问日志
Cloudflare R2（若你启用了 APK 更新分发）存放安装包下载文件同上是对象存储的常规访问记录
企业微信 / 钉钉机器人 Webhook（你可选配）把新反馈推送到你的群机器人你填写的那个机器人地址，消息含反馈类型与摘要
你的浏览器 / 手机系统本地缓存、二维码与蓝牙打印数据不出本机
如果你的部署没有配置反馈 Webhook，那么反馈提醒不会发往任何外部平台，只在系统内以红点提示管理员。

7. 你的权利

你是自己数据的控制者，可以随时行使以下权利（均由管理员在系统内操作，或直接操作数据库）：

  • 访问与查看：在「商品 / 客户 / 订单 / 分析」各页面查看全部数据。
  • 导出：订单、商品清单支持导出 Excel（含单价、折扣、金额公式）。
  • 更正：直接编辑订单、商品、客户资料。
  • 删除：删除订单、商品、客户；删除套账（老板权限）。删除订单时会同步清理该门店的历史价格记忆。
  • 撤回反馈附件：管理员可删除反馈记录；附件文件本身请在服务器 uploads/feedback/ 中清理。
  • 注销账户：由管理员在「设置 - 账户与角色管理」中删除该账户。
  • 解除信任设备：「设置 - 信任设备」可随时解除任何已记住的设备。

关于「删除」的诚实说明

SQLite 数据库没有「回收站」概念。订单被删除后无法撤销；若你需要留档，请先在「订单」页导出 Excel 再删除。库存数量会在删除订单时自动回补，历史价格记忆同步清除。

8. 安全措施

  • 密码使用 scrypt 加盐哈希，不可逆。
  • 全部接口按套账与角色双重隔离，越权访问返回 403。
  • 登录失败 3 次后强制图形验证码；登录接口带失败次数与 IP 限流。
  • 注册必须填验证码，防止批量注册。
  • 上传文件名重新随机生成，且只放行白名单扩展名，杜绝路径穿越与可执行文件伪装。
  • 跨域请求按来源白名单放行，非白名单来源读不到接口数据。
  • 建议：务必用 HTTPS 部署（本项目自带可选 HTTPS 监听）；数据库文件权限设为仅服务进程可读；不要把 3000 端口直接暴露到公网（本项目默认已收窄到 127.0.0.1）。

9. 未成年人

本系统面向企业门店的经营与开单场景，不面向未成年人。若未满 18 周岁的未成年人需要使用，应在监护人陪同下由企业管理员创建账户，并对该账户的操作范围作适当限制。
